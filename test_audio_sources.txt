Audio sample source and validation record
=========================================

Download date: 2026-11-05
Dataset: WaveFake: A Data Set to Facilitate Audio DeepFake Detection
Original research dataset: https://zenodo.org/records/5642694
Original DOI: https://doi.org/10.5281/zenodo.5642694
Research code: https://github.com/RUB-SysSec/WaveFake
Accessible row API used for these files:
https://datasets-server.huggingface.co/first-rows?dataset=ajaykarthick/wavefake-audio&config=default&split=train
Mirror dataset page: https://huggingface.co/datasets/ajaykarthick/wavefake-audio

The WaveFake labels are not guessed:
- `R` is the dataset's real/reference recording label.
- `WF1` is the dataset's first WaveFake generated-system label.
- Each numbered pair uses the same original utterance ID, with one R and one WF1 file.
- The source collection is speech data. Validation below confirms decodable,
  non-silent audio and runs the project's 16 kHz/mono/3-second/Mel pipeline.

Validation:
- Downloaded and usable: 10 REAL, 10 FAKE, 20 total.
- Rejected: none.
- All files were non-empty, decoded with Librosa, finite, longer than 0.5
  seconds, and not silent/near-silent by RMS/peak checks.
- All files passed the project's compatibility preprocessing: resampling to
  16,000 Hz mono, trim/zero-padding to 3 seconds, and 128-band Mel
  spectrogram generation with n_fft=2048 and hop_length=512.
- The source dataset identifies these as speech clips; no speech-recognition
  service was used. The local audio-content check is a technical
  non-silence/decodability check, not a human transcription.
- No model predictions or accuracy claims are made by this download step.
- The application uses the SHA-256 values in `test_audio_download_metadata.json`
  only to recognize these exact, unchanged demo files. For a known file, the UI
  displays the verified dataset label and also reports the CNN prediction
  separately; this must not be interpreted as corrected CNN performance.
